# countingbot
A Slack bot that can be added to "counting" channels, where the only purpose of the channel is to count.
It can understand numerics and numbers written in English. Numbers that are correct are marked with 
:white_check_mark: and numbers that are incorrect are marked with :bangbang: (this also happens if a
user counts twice in a row)

## Note on AI usage
AI was used in the making of this project. Where AI was used, there will be a comment at the top of the
file that notes how much and for what purpose AI was used.
